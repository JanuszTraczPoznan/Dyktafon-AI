# Schemat działania systemu

## Krótkie nagrania

Telefon z aplikacją Dyktafon → webhook Make → Google Gemini → Google Sheets i widok HTML

## Długie nagrania

Telefon z aplikacją Dyktafon → Google Drive → scenariusz Make → Google Gemini → Google Sheets i widok HTML

## Główna zasada

Jedno nagranie jest analizowane tylko jeden raz przez Google Gemini. Wynik zawiera transkrypcję, podsumowanie, uczestników, ustalenia, zadania i terminy.

## Bezpieczeństwo

Publiczne repozytorium nie zawiera kluczy API, adresów webhooków, identyfikatorów Google ani danych klientów.
