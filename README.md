# Dyktafon-AI

System automatycznej transkrypcji i analizy nagrań z wykorzystaniem Make oraz Google Gemini.

## Zawartość projektu

Folder `make` zawiera dwa oczyszczone scenariusze Make:

1. Dyktafon oraz transkrypcja na osoby.
2. Dyktafon — duże nagrania z Dysku Google.

## Import scenariuszy

Po zaimportowaniu blueprintu do Make należy podłączyć własne połączenia, webhook, foldery Dysku Google oraz arkusz Google Sheets.

## Bezpieczeństwo

Opublikowane blueprinty nie zawierają kluczy API, tokenów, haseł ani prywatnych identyfikatorów używanych w działającym systemie.
